# BEAUTY WOMAN

Sistema web para la gestión de productos de **BEAUTY WOMAN**, desarrollado como proyecto académico para la práctica de desarrollo web y control de versiones con Git y GitHub.

##  Descripción

**BEAUTY WOMAN** es un proyecto web orientado a la administración y gestión de productos. El proyecto cuenta con un apartado frontend y backend, además de una base de datos para almacenar la información necesaria del sistema.

Durante el desarrollo también se realizaron prácticas de control de versiones utilizando **Git**, trabajando con ramas, commits, modificaciones, renombrado de archivos y combinación de ramas.

##  Tecnologías utilizadas

## Práctica de Git

Durante la práctica se realizaron las siguientes actividades:

1. Configuración del usuario y correo de Git.
2. Creación y seguimiento de archivos.
3. Uso de `git status`.
4. Agregado de archivos con `git add`.
5. Creación de commits.
6. Modificación de archivos.
7. Consulta del historial con `git log`.
8. Creación de la rama `Devoluciones`.
9. Cambio entre ramas.
10. Creación del formulario de devoluciones.
11. Renombrado de `Registro-Devoluciones.html` a `Formulario-Devoluciones.html`.
12. Integración de la rama `Devoluciones` en `master`.
13. Eliminación de la rama `Devoluciones`.

## Archivos de la práctica

### Inicio de sesión

`inicio-sesion.html`

Contiene un formulario básico para ingresar al sistema mediante usuario y contraseña.

### Entrada de productos

`entrada-producto.html`

Permite registrar información relacionada con la entrada de productos.

### Salida de productos

`salida-productos.html`

Contiene un formulario para registrar la salida de productos.

### Formulario de devoluciones

`Formulario-Devoluciones.html`

Permite registrar una devolución indicando:

* Producto
* Cantidad
* Motivo de devolución

## Ramas utilizadas

Durante la práctica se trabajó principalmente con las siguientes ramas:

* `master` — Rama principal.
* `omar` — Rama de trabajo.
* `Devoluciones` — Rama utilizada para desarrollar el formulario de devoluciones.

La rama `Devoluciones` fue integrada posteriormente a `master`.
